Q&A — Your One-Liners Answered

1. Images/txt → standard 4-sheet Excel (Title, Work Order, Bill Quantity, Extra Items)?
Partially. The OCR extractor (ingestion/ocr_extractor.py) parses text to a unified model. The excel_exporter.py can write it back to Excel. Tesseract OCR is not installed — uses mock fallback. Real image OCR needs Tesseract installed. Text files work via the same pipeline.

2. Six standard outputs in PDF?
YES — all 3 test files produce 6 HTML + 6 PDF outputs (7 including last_page). Chrome PDF engine is the best; falls back to pdfkit/WeasyPrint. The SAMPLE_PACK/03_consolidated_outputs/ folder has all PDFs from the last run.
